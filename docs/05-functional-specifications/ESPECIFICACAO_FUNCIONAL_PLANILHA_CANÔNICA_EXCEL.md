# Especificação Funcional — Planilha Canônica de Gestão Estratégica

A Planilha Canônica é um canal portátil da Plataforma SPARKs. Quando o SaaS for a fonte oficial, a planilha representa uma exportação controlada. Quando a organização ainda não opera no SaaS, o modelo vazio poderá apoiar a gestão estratégica e futura importação.

## Regras centrais

1. A exportação é sempre filtrada por organização e projeto.
2. Não existe fallback para projeto de outra organização.
3. O arquivo recebe manifesto, versão de esquema e dados de origem.
4. A geração é auditada.
5. A planilha contém navegação, dashboard e abas para toda a jornada estratégica.
6. Campos importados são apresentados em verde; entradas manuais, em azul; fórmulas, em preto.
7. O modelo vazio não contém dados da COOTAQUARA nem de qualquer cliente.

## Abas do modelo canônico

Capa, Instruções, Configuração, Organizações, Projetos, Fases, Governança, Pessoas e Papéis, Evidências, PESTEL, SWOT, TOWS, Riscos e Lacunas, Direcionadores, Identidade Estratégica, Temas Estratégicos, Objetivos, Mapa Estratégico, OKRs, KRs, Indicadores, Metas, Iniciativas, 5W2H, Acompanhamento, Decisões, Artefatos, Validações, Aprendizados, Portabilidade, Dashboard e Dicionário de Dados.
